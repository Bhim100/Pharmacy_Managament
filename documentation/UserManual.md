# User Manual

## Login / Start

Open the dashboard page from the `frontend/` folder to view the project modules.

## Inventory

- Add medicine records
- Add new stock batches
- Check low-stock and expiry-prone medicines

## Billing

- Enter customer ID
- Select medicine and batch
- Enter quantity
- Generate bill

## Reports

- View inventory summary
- View expiring medicines
- View customer purchase history
- View daily and monthly sales

## Admin

- Run reorder alert procedure
- Run expired medicine disposal procedure
- Use admin queries for data validation
